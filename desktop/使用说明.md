# Parcel 桌面版

双击桌面的「Parcel 日程与番茄钟」即可使用。

## 先开始使用

1. 自动排程、待办事项、历史记录从左到右排列。拖动分隔线可以调整栏宽。主窗口默认占满屏幕可用高度，宽度约为屏幕的 60%。
2. 新增或编辑待办时，按番茄数填写预计和已投入的工作量。25 分钟实际工作算 1 个番茄，20 分钟算 0.8 个，休息不计。顶部进度条按整颗番茄累计，满格为 16 个番茄。
3. 在「更多 → 计时 / 排程设置」里设置每周可用时间、休闲保护时段和番茄钟时长。默认滚动排程 21 天。点击自动排程标题左边的「◂」收起面板，再点击「展开排程 ▸」恢复。
4. 「固定日程」可以录入单次或每周重复的课程、会议等。Google 课表在同一列表中显示，时间轴用偏黄的橙色标记课程，自动排程会避开。要调整导入的课程，请在 Google 日历修改。
5. 点击「打开番茄钟」，默认显示当前或下一段排程的任务；点击「自定义任务」可以切换任务，检查本次时长后点击「确定开始」。
6. 悬浮番茄钟始终置顶，可以拖动圆环移动位置，支持暂停、继续和结束本次；关闭小窗口只会隐藏，计时继续。
7. 中途结束会记录实际工作时长；暂停时间不计入。一次工作完成后会进入短休息，每四轮进入长休息。默认下一阶段手动开始，可在设置里改为自动。
8. 排程在每小时的 :00 和 :30 自动刷新；修改任务或记录工作后会立即更新。右侧日期下拉框可查看其他天。
9. 在待办行点击「开始」，确认时长后启动该任务的番茄钟。点击「编辑」后，可以用「已完成」标记任务，或用「删除待办」移除任务。勾选「显示已完成」可重新打开已完成的任务。
10. 双击历史里的备注可以修改。
11. 首页右下角的「问题与反馈」可以记录问题或改进想法。点「提交」后，每条反馈会单独保存在本机数据文件夹的 `parcel.feedback` 子文件夹中。

## 冲突与手动调整

- 红色排程状态可以点击，查看未能排入的工作和具体原因。
- 旧数据中的过期截止日期不会自动改成今天。请按实际需要编辑；也可在开始专注时明确确认一次手动例外。
- 「调整 / 锁定」可以修改某段工作开始时间并锁定。只能锁定满足可用时间与约束的时段；之后可点击「解锁」。固定日程在独立管理窗口编辑。
- 最短连续工作时长是硬约束；中途结束后，如果剩余工时小于最短时长，需编辑该值或在开始本次专注时确认例外。
- 新增待办时，前置任务列表只显示未完成的任务。编辑时可按住 Ctrl 多选。循环依赖无法保存；前置任务无法排入时会提示后续任务受阻。
- 地点 / 环境留空时不限制；在设置中选择当前环境后，有环境要求的任务只会在匹配时排程。
- 「精力状态」和「工作类型」可以同时选择，各自生效 1 小时，到期自动回到「正常」。偏好只用于这一小时内开始的自动工作段，截止日期与大类优先级排在前面。可以在首页「大类设置」里设优先级。
- 待办栏可展开「筛选」，默认隐藏休闲待办。新增或编辑待办时，展开「其他设置」可填写地点、任务描述和不常用的时间字段。
- 新增待办时，「任务类型」默认用离线规则识别标题和描述，例如「完善项目概念」是输出，「看几篇论文」是输入。判断不明确时保存为「普通」，也可以手动选类型。编辑旧待办时保留原类型，可手动选择「自动建议」。
- 「更多 → 快捷文字录入」支持“明天 画草图 2小时”等明确格式，识别后会打开编辑框供确认。这是本地规则识别。

## 数据和退出

- 如果本机有旧版 TomatoManager 数据，新版首次启动时可以导入。两版之后各自保存数据。
- 历史旧记录缺少暂停期间的实际用时，沿用旧软件每次工作所对应的 25 分钟；新版按实际计时记录。
- 新版数据位于程序旁的 `data/parcel.json`，每日首次修改前自动保存一份到 `data/backups`。可以通过「更多」打开数据文件夹或另存完整备份。
- 关闭主窗口后保留在右下角系统托盘。彻底退出请用「更多 → 退出 Parcel」或托盘菜单。
- 退出时保存计时进度。下次打开会暂停恢复，退出期间不自动算作工作；运行期间电脑休眠会按经过的时间推进当前阶段，最多记录当前这一轮。
- 时间统一使用 Europe/London，自动处理夏令时。旧记录的时间文字按原数据保留。

## 可选的 Notion 双向同步

1. 在 Notion 新建一个专用页面，建议设为私有。到 [Notion 开发者后台](https://www.notion.so/my-integrations) 为同一工作区创建一个内部连接，开启读取、插入和更新内容权限。回到刚建的页面，点右上角「··· → 添加连接」，选中这个连接。
2. 从托盘彻底退出 Parcel。在 `Parcel.exe` 所在文件夹打开 PowerShell，粘贴下面这段。按提示输入刚建的页面链接和内部连接令牌。令牌输入时会遮盖，保存在当前 Windows 用户的环境变量中，不会写入 Parcel 的文件或备份。请在本机输入令牌。

```powershell
$page = Read-Host 'Notion 页面链接'
$match = [regex]::Match(($page.Split('?')[0].TrimEnd('/')), '(?i)[0-9a-f]{32}$|[0-9a-f]{8}(?:-[0-9a-f]{4}){3}-[0-9a-f]{12}$')
if (-not $match.Success) { throw '找不到 Notion 页面 ID，请使用页面的复制链接功能。' }
$secret = Read-Host 'Notion 内部连接令牌' -AsSecureString
if ($secret.Length -eq 0) { throw '请输入令牌。' }
[Environment]::SetEnvironmentVariable('PARCEL_NOTION_TOKEN', [System.Net.NetworkCredential]::new('', $secret).Password, 'User')
New-Item -ItemType Directory -Force -Path data | Out-Null
@{ parent_page_id = $match.Value } | ConvertTo-Json | Set-Content -Encoding utf8 -LiteralPath 'data/parcel.notion.json'
```

3. 用原来的快捷方式打开 Parcel。第一次连接会在该页面建立「Parcel · 待办事项」和「Parcel · 专注历史」两张表并上传本机记录，耗时随记录数增长。以后 Parcel 启动时，以及程序运行期间伦敦时间每个整点和半点同步。同步记录可查看 `data/parcel.notion.log`。

- 两边都可以新增和编辑。新增 Notion 行时填写「任务」，「Parcel ID」留空，程序会自动分配。日期列使用 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM` 的伦敦本地时间。请保留列名和列类型。
- 删除不会同步。一条记录只要还在其中一边，下次同步就会补到另一边。双方改不同字段时分别保留。双方改同一个字段时，非空优先；备注和描述会保留两份文字，其余字段以本地为准。
- 固定日程、锁定时段、软件设置和正在计时的状态保留在本机。当前计时的任务等计时结束后才参与同步。在线增改历史记录会更新历史表，待办的已投入工时可在待办表单独修改。
- 断网或 Notion 暂时不可用时照常使用 Parcel，下次同步会重试。要停用同步，移走 `data/parcel.notion.json` 后重启 Parcel。

## 快捷键

- Ctrl+N：新增待办
- Ctrl+空格：打开番茄钟
- F5：重新排程

源码在项目文件夹。排程使用本地规则，可离线使用。
