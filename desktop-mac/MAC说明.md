# Tomato Mac 适配版

源代码：用户下载的 PileCarrot/Parcel，提交 e50d506a656c28aacf4c92d144b9206203cb9ae3，desktop 目录。它是 Python/Tkinter 的日程与浮动番茄钟程序，和 outputs/parcel 中的 Expo 原型是两份不同工程。

## 当前产物

`dist/Tomato.app`：为这台 Apple Silicon Mac 构建的独立应用，内含 Python/Tk 运行环境。无需启动网页或安装 Python。

双击 `安装Tomato到Mac.command` 将应用复制到个人 Applications 目录并建立桌面快捷方式。已有 Tomato 应用会先改名备份。旧 Parcel 预览启动器只改名标记，不删除。安装步骤遵照用户睡前指示，未自动执行。

## 已做的 Mac 适配

- 使用 PingFang SC 中文字体，调整窗口尺寸，给菜单栏和 Dock 留空间。
- 使用 Finder 打开数据文件夹，替换 Windows 专用命令。
- 不启动 Windows 托盘线程；当前 Mac 版关闭主窗口即保存并退出。
- 增加 Command-N 快捷键。
- 数据保存在 `~/Library/Application Support/Tomato/parcel.json`，沿用 Windows JSON 格式与备份机制，不写入应用包。
- 添加进程锁，避免重复启动同时写入同一目录数据。
- 保留浮动番茄钟、计时恢复、任务、排程以及原有 Notion 同步代码。

## 2026-11-06 自动同步更新

- “更多 → 设置 Notion 自动同步”在本机输入已有集成令牌，验证已有数据库读取权限后保存到 Mac 钥匙串。配置 JSON 不含令牌。
- 打开时同步；任务或历史记录修改后等待 5 秒合并同步；每个整点、半点检查远程更新。退出应用后停止。正在计时的任务跳过远程合并。
- 不同字段独立合并；同一字段两边修改时，用本机该字段的保存时间和 Notion 该行最后修改时间比较，较新的值优先，双方旧值留在 notion_sync.conflict_archive。Notion 只提供行级时间，因此对另一字段的更新也可能影响该行比较；不同电脑时钟也需准确。缺失修改时间、同一时刻等情况保留双方值，使用“处理同步冲突”选择。
- 未扩展到删除传播，远程消失的记录仍保留；不宣称支持删除同步。
- Windows 现有程序仍遵循其原同步节奏与冲突算法；要使两端完全一致，需要将本次对应源代码更新安装到 Windows。
- 37 项不依赖真实账户的后台测试通过（核心 21、传输与合并 13、调度 3）。实际云端连接必须等用户完成令牌输入才能验证。
